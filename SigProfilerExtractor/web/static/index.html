SigProfiler Suite · de novo mutational signatures

Find the mutational signatures shaping your samples

Every process that damages DNA, from tobacco smoke and ultraviolet light to failing DNA repair, leaves its own pattern of mutations. SigProfilerExtractor separates a cohort's mutations into those patterns, mutational signatures, and reports how much each one contributed to every sample. It tries every plausible number of signatures, keeps the most stable solution and matches it to the COSMIC catalogue of known signatures.

This Workbench runs it on your own computer, from variant calls or a ready-made matrix to an interactive report, without writing code.

The example finishes in about three minutes on a laptop.

You give

one cohort per run
  • Variant callsA folder of VCF files, one per genome (MAF and simple text work too). Matrices are built for you by SigProfilerMatrixGenerator.
  • A mutation matrixMutation types down the rows, samples across: SBS96 to SBS4608, DBS78, ID83, CNV48 or SV32.
  • Structural variantsA folder of BEDPE files, classified into the 32 SV channels.
  • Copy-number segmentsOne segmentation file from ASCAT, Battenberg, FACETS, PURPLE, Sequenza and others, classified into 48 CNV channels.

You get

for every mutation type
  • How many signaturesThe suggested number, chosen from stability and reconstruction error across every number tried.
  • De novo signatures and activitiesEach signature's profile, and how many mutations it contributed to each sample.
  • COSMIC decompositionEach de novo signature explained by known COSMIC signatures (v3.6 by default), with sample activities.
  • Mutation probabilitiesWhich signature most likely caused each mutation type in each sample.
  • Plots and an interactive dashboardPDFs for every solution, and a self-contained report to explore and share.

How it works

the method of Islam et al., Cell Genomics 2022
  1. 1MatricesVariant calls are counted into mutation matrices (SBS96, DBS78, ID83 and more), one column per sample.
  2. 2Many factorizationsFor each candidate number of signatures, non-negative matrix factorization runs on many resampled copies of the data: 100 by default.
  3. 3Stable signaturesThe replicate solutions are clustered. A signature found again and again across replicates is stable.
  4. 4The number of signaturesThe suggested solution is the largest stable one that still reconstructs the samples well.
  5. 5Match to COSMICSigProfilerAssignment explains each de novo signature with known COSMIC signatures and assigns them to every sample.
BenchmarkedCompared with 13 other tools on more than 60,000 simulated cancer genomes, it found more of the true signatures and far fewer false ones.
ReproducibleEvery run records its seed in Seeds.txt. Give it back to repeat the run exactly.
PrivateEverything runs on this computer. Your data never leaves it.
Same results as codeThe Workbench calls the same function as Python and the command line, and writes the same files.

Getting started

          

            
A run has three parts: set it up on New run, follow it on Monitor,
              and explore it on Results. The fastest way to see all three is the
              21 breast cancer genomes example with the Quick look preset: about three minutes.

          

        

        

          
1. Choosing the input

          

            

              
Variant calls
A folder of VCF files, one per sample (MAF and SigProfiler
                simple text are read too). Choose the genome they were called against; the
                matrices are built by SigProfilerMatrixGenerator, which writes input/
                and output/ folders into that folder.

              
Mutation matrix
One tab-separated file: mutation types in the first column,
                one column per sample. Its context follows from the number of rows: 96, 288, 384,
                1536 or 4608 for SBS, 78 for DBS, 83 for ID, 48 for CNV and 32 for SV. Empty and
                all-zero samples are dropped; samples with some values missing stop the run.

              
Structural variants
A folder of BEDPE files, one per sample. The SV32
                matrix is written to an SV_Matrices folder beside it.

              
Copy number
One segmentation file covering every sample, and the caller
                that made it.

            

          

        

        

          
2. How much searching

          

            
For every number of signatures from the fewest to the most, SigProfilerExtractor
              runs the factorization once per replicate. The work is contexts × numbers ×
              replicates, which the estimate under the presets adds up. Quick look (1 to 5,
              10 replicates) is for a first look; Standard (1 to 25, 100 replicates) is the
              published setting, and what results for a paper should use.

          

        

        

          
3. Reading the results

          

            

              
Suggested solution
The number of signatures SigProfilerExtractor chose for
                each context, its de novo signatures and their activities, in
                <context>/Suggested_Solution.

              
All solutions
Every number tried, with stability and error statistics, in
                <context>/All_Solutions; the selection plot shows how the
                number was chosen.

              
COSMIC decomposition
The de novo signatures explained by COSMIC signatures,
                and the COSMIC activities per sample.

              
Dashboard
reports.html, written by SigProfilerExtractor
                itself: open it here, in a new tab, or send it to a colleague; it needs nothing else.

            

          

        

        

          
4. Stopping the Workbench

          

            
Quit in the top bar stops the app and any run still going. From a terminal,
              ./launch_web.sh --stop does the same. Results already written stay.
